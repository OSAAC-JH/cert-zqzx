## 출제 구성과 내용 검토

공식 출제표에 따른 35·30·35문항과 세부과목 배분을 유지했다. 단순 사례 번호 교체를 없애고 금융 계산, 주문 집행, 기업 지분, 고객 상황, 법정 원칙을 별도로 묻도록 전수 재구성했다. 04 문항을 그대로 복사하지 않았다. 개정 문항은 난이도를 무리하게 ‘고난도’라고 단정하지 않는다.

각 문항의 네 선택지를 조건과 대조해 하나의 정답만 성립하도록 검토했고, 해설에 계산 과정 또는 오답의 혼동 원인을 제시했다. 기술적 신호는 가능성으로 설명하며 추세전환을 확정하지 않는다. 법규 문항에는 일반·전문소비자, 권유 유무, 적용대상·예외를 필요한 범위에서 명시했다. 세율·과세 요건이 문제의 전제인 경우 그 사실을 명시했고 최신 세법 수치를 추정해 넣지 않았다.

특히 Q16은 미체결 매수 주문이 먼저 대기한 뒤 매도주문이 들어오는 상황으로 명확히 했다. Q39는 펀드 기준가격의 ‘1,000좌’ 단위까지 적용했다. Q90은 출석 600주 중 찬성 390주로 특별결의 400주 기준에 미달하고, Q91은 출석 과반수를 넘더라도 발행총수 1/4에 미달하는 경우를 구분했다.

문항별 판단 포인트·정답 텍스트·해설 대조표는 아래 전수 검토표와 `tests/mock05-review.json`에 있다. 이 JSON은 생성기에서 가져온 답안의 사후 변경·인덱스 이동을 탐지하는 기준 데이터이며, 그 자체가 외부 전문가의 독립 검증을 뜻하지 않는다. 계산·채점은 별도 수식과 경계값 테스트로 다시 확인한다.

## 검증

`npm test`: 44개 통과. 중복·필드·정답 인덱스·선택지 중복·과목/세부과목 수·홈페이지 연결, 30개 독립 계산·수치 판단, 총점 69/70 및 각 과목 과락 경계값 등을 확인한다.

`npm run test:browser`: [GitHub Actions 실행 38562720667](https://github.com/OSAAC-JH/cert-zqzx/actions/runs/38562720667)에서 Chromium·Firefox·WebKit 모두 1280×900, 390×844, 320×640 및 저장소 차단 시나리오 통과(총 12개 시나리오). 정적·계산·채점 44개 테스트도 동일 실행에서 통과했다. 결과 로그는 Actions 아티팩트 `mock05-browser-results`에 보존했다. 로컬에서는 Chromium으로 같은 모바일·데스크톱 동작을 추가 확인했다.

브라우저 검증 시나리오: 홈페이지 진입, 100문항 렌더링과 응답 이벤트, 응답 잠금, 개별/전체 해설, 미풀이 제외 오답 필터와 과목 필터 결합, 빈 목록 안내, 채점/오답 이동, 테마 복원, 새로고침 복원, 초기화 취소·확인, 이전 기록 보존, 손상 JSON·저장소 차단, 가로 넘침·미처리 JS 예외.

재실행: Node.js 22 이상에서 `npm ci`, `npm test`, `npx playwright install --with-deps chromium firefox webkit`, `npm run test:browser`. 브라우저 설치나 실행 실패를 통과로 처리하지 않으며 기본 실행은 세 엔진 모두 요구한다. 로컬 진단에 한해 `MOCK05_BROWSERS`와 `MOCK05_CHROMIUM_PATH`를 사용할 수 있다. 스크린샷은 OS 임시 폴더에 기록한다.

자동화는 동일 텍스트·선택지 조합과 수식·동작 오류를 탐지한다. 의미상 중복과 법적 해석의 모든 가능성을 자동 증명하지는 않는다. 원교재 전권과의 공식 감수 또는 실제 Android/iOS 기기 검증은 수행하지 않았다. 모바일 검증은 해당 화면 크기의 브라우저 엔진에서 수행한다.
